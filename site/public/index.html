Setting up takes ten minutes

Install on your PC

Download Guardian, make your account, and confirm it with the code we email you.

Install on their PC

From an administrator account, run the Child PC installer. Write down the Device ID and pairing code it shows. Make sure their own Windows account is a standard account.

Link them

In Guardian, open Settings, type the Device ID and pairing code, and you're watching. Updates install themselves from then on.

Questions

Windows says "unknown publisher". Is that normal?

Yes. Guardian isn't signed with a paid certificate yet. Click More info, then Run anyway.

Does my PC need to be on?

For now, Guardian connects over your home Wi-Fi, so a parent PC with Guardian running needs to be on the same network.

Can they uninstall it?

Not from a standard Windows account. Removing it needs an administrator password.

I forgot my password

Type it wrong five times, or press Forgot password, and we'll email you a reset code. You can also reset it here.
